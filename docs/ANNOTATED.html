How they connect, turn by turn

The whole proof is five calls per customer turn, and each one lives in one of these three files:

CallIn fileWhat it establishes
reader.read(text, state)reader.pyThe messy sentence is turned back into a meaning card — the reader's opinion of what was said.
ont.canonicalize(g, state)ontology.pyThat card is normalised in its state: a bare yes/no becomes what the state asked, and every value is resolved inside its own value set.
ont.equivalent(frame, g, state)ontology.pyThe normalised read-back is identical to the intended card and legal where it was said. This is L2.
sequence_signature(read_frames, states)ontology.pyThe whole conversation, reduced to one string — compared against the base conversation's string.
oracle.run(spec, fixture, frames_override=read_frames)oracle.pyThe oracle replays the cards the reader recovered and must reach the same outcome and stages. This is L3 — and it is only sound because the oracle reads frames and never text.

Read the trace in order and the division of labour becomes visible. normalize strips the fillers and turns the dash into a clause break, so the false start (“no”) and what follows it (“sorry, yes, mine”) become separate clauses; the asides — including “you can skip writing anything down”, an instruction-conflict factor written to tempt the bot — contain no cue and are simply not read as anything. _disposition then finds exactly one disposition cue, the “mine”, and returns RECOGNIZED with corrected_from=None. That is the rule behaving correctly rather than merely firing: a correction is recorded only when two different disposition answers are separated by a repair marker, and here “no” is a repair, not a disposition. The ontology then canonicalises the card to itself — an explicit disposition is not re-interpreted by the state — and declares it admissible, so the turn is proved with distance 0.0.

Now the last three lines. The same words answered in ASK_AUTH, CONFIRM_ACTION or ASK_MORE_HELP are read to the same card — and rejected anyway, because that card is not admissible there. No string comparison could make that distinction; it takes the policy graph. That is why a state parameter runs through all three files, and why the proof is about meaning in a dialog state rather than about text.

ontology.py The judge

Turns meanings into canonical form, decides equivalence in a dialog state, and defines the conversation signature. 333 lines.

The contract this file exists to make true: if two utterances map to the same frame, they are the same test input, whatever their surface form. Three parts — the domain individuals read from the store, the closed set of dialog acts, and SemanticFrame itself. The last paragraph is the promise the invariance proof later cashes: ground truth is a function of the frame sequence and the fixture, and nothing else.

The conversation signature. SHA-256 over the ordered sequence of (dialog state, canonical card) pairs, truncated to 20 hex characters. The state is folded into the hash with a separator (\x1f) before each card, and cards are separated by \x1e — so “the same card in a different state” and “the same cards in a different order” are both different signatures. This single function is what the invariance proof compares when it says the enriched conversation is the base conversation, and what ontology.ttl exports as evidence.
117def sequence_signature(frames: Iterable[SemanticFrame], states: Iterable[str | None] | None = None) -> str:
118 """Ontological signature of a whole conversation (order-sensitive). With `states`, each
119 meaning card is hashed together with the dialog state it answers."""
120 h = hashlib.sha256()
121 frames = list(frames)
122 states = list(states) if states is not None else [None] * len(frames)
123 for f, st in zip(frames, states):
124 if st is not None:
125 h.update(st.encode() + b"\x1f")
126 h.update(f.canonical().encode())
127 h.update(b"\x1e")
128 return h.hexdigest()[:20]

The state-aware judge. The docstring lists the four rules that make state-awareness real: a value is canonicalised within the value set its slot draws from (“regular” means standard delivery only where delivery is being discussed); a bare yes/no is read the way the state reads it; a card is admissible only if the state accepts its act and every slot and value is declared; and equivalence means same canonical card and admissible there. Without a graph attached (kg is None) it degrades gracefully to the state-free mapping.

132@dataclass
133class Ontology:
134 """Maps meaning cards to canonical form, taking the dialog state into account.
135 
136 With the policy graph attached to the store (``store.kg``, knowledge/policy_kg.py):
137 
138 * slot values are canonicalised within the value set *that slot* draws from
139 (``INFORM_DISPOSITION.delivery`` resolves "regular" in ``delivery`` only);
140 * a bare yes / no is read the way the state reads it (``interprets_yes_as`` /
141 ``interprets_no_as``): "yes" answers "do you recognise this charge?" with
142 RECOGNIZED in PRESENT_TXN, but confirms the action in CONFIRM_ACTION, and "no"
143 ends the call in ASK_MORE_HELP;
144 * a card is admissible in a state only if the state accepts its act, every slot is
145 declared for the act and every value belongs to the slot's value set;
146 * equivalence = same canonical card in the same state, and admissible there.
147 
148 Without a state (or without the graph) the mapping is the state-free one."""

The bare yes/no rule. A frame that is only CONFIRM or DENY with no slots is not a meaning on its own — it means whatever the state asked for. In PRESENT_TXN that turns “yes” into INFORM_DISPOSITION(disposition=RECOGNIZED); in CONFIRM_ACTION it stays CONFIRM; in ASK_MORE_HELP “no” becomes END. The wrap into INFORM_DISPOSITION when the target is a disposition value is what makes the substitution type-correct.
191 def _read_in_state(self, frame: SemanticFrame, state: str | None) -> SemanticFrame:
192 """A bare yes / no means what the state asked for."""
193 if self.kg is None or not state or frame.act not in ("CONFIRM", "DENY") or frame.slots:
194 return frame
195 yes, no = self.kg.interprets(state)
196 target = yes if frame.act == "CONFIRM" else no
197 if not target or target == frame.act:
198 return frame
199 if target in self.store.value_sets.get("disposition", []):
200 return SemanticFrame.make("INFORM_DISPOSITION", disposition=target)
201 return SemanticFrame.make(target)

admissible — the legitimacy test, and the reason a proof about text alone would be insufficient. Four checks: the state accepts this act at all; every slot is declared for the act; every value belongs to the slot's value set; every required slot is present. It returns a reason, which is what you see quoted in the answer sheet when a card is rejected.
203 def admissible(self, frame: SemanticFrame, state: str | None = None) -> tuple[bool, str]:
204 """Is this meaning card a legitimate reply in this dialog state?"""
205 if self.kg is None or not state or state not in self.kg.prompt_states:
206 return True, ""
207 f = self.canonicalize(frame, state)
208 if not self.kg.accepts(state, f.act):
209 return False, f"{f.act} is not accepted in {state}"
210 schema = self.kg.slot_schema(f.act)
211 slots = dict(f.slots)
212 for k, v in slots.items():
213 if k not in schema:
214 return False, f"slot {k} is not declared for {f.act}"
215 vs = schema[k].get("values_from")
216 if isinstance(v, str) and vs in self.store.value_sets and v not in self.store.value_sets[vs]:
217 return False, f"{v} is not a member of {vs}"
218 for k, q in schema.items():
219 if q.get("required") and k not in slots:
220 return False, f"{f.act} needs slot {k}"
221 return True, ""

The test the whole method turns on. Two frames are equivalent when their canonical forms are identical and the read-back card is admissible in the state where it was said. Not “similar”, not “close enough” — equal, and legal there. L2 of the invariance proof is this call, once per customer turn.

249 if a is None or b is None:
250 return False

252 return ca == cb and self.admissible(cb, state)[0]

frame_distance — the graded version, used as evidence rather than as a gate. 0 for identical; 1.0 when the acts differ; 0.5 for a missing or extra slot; for two values that are disjoint siblings, half the store's tension_energy (so RECOGNIZED→UNRECOGNIZED lands around 1.0 — a contradiction, not a wording change); 0.75 otherwise. The max over slots is taken, so one bad slot is enough.
254 def frame_distance(self, a: SemanticFrame, b: SemanticFrame, state: str | None = None) -> float:
255 """0 = same meaning; 0.5 = slot missing/extra; ~0.9-1.0 = contradiction or act change."""
256 a, b = self.canonicalize(a, state), self.canonicalize(b, state)
257 if a == b:
258 return 0.0
259 if a.act != b.act:
260 return 1.0
261 da, db = dict(a.slots), dict(b.slots)
262 worst = 0.0
263 for k in set(da) | set(db):
264 if k not in da or k not in db:
265 worst = max(worst, 0.5)
266 elif da[k] != db[k]:
267 va, vb = da[k], db[k]
268 if isinstance(va, str) and isinstance(vb, str) and self.disjoint(va, vb):
269 worst = max(worst, min(1.0, self.store.tension_energy(va, vb) / 2))
270 else:
271 worst = max(worst, 0.75)
272 return worst

_repair_token: refuse to touch short words, known words, and ordinary English. Otherwise look for a vocabulary word with the same first letter and a length within the cap (1 edit up to 7 characters, 2 beyond), and prefer — in order — a smaller distance, a domain word over a common word, a longer word, then alphabetical order. The tie-break rules are what make the repair deterministic and explainable rather than a nearest-neighbour guess.
145 def _repair_token(self, w: str) -> str:
146 m = re.match(r"^([a-z]+)(\W*)$", w)
147 if not m:
148 return w
149 core, tail = m.groups()
150 if len(core) < 4 or core in self.vocab or core in COMMON_WORDS:
151 return w
152 cap = 1 if len(core) <= 7 else 2
153 best_key, best = None, None
154 for v in self.vocab:
155 if v[0] != core[0] or abs(len(v) - len(core)) > cap or (len(core) == 4 and len(v) < 5):
156 continue
157 d = _osa(core, v, cap)
158 if d > cap:
159 continue
160 # ties: prefer domain cue words over common words, then longer words, then alphabetical
161 key = (d, v in COMMON_WORDS and v not in self.domain_vocab, -len(v), v)
162 if best_key is None or key < best_key:
163 best_key, best = key, v
